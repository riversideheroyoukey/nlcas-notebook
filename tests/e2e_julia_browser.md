## シナリオ C3 — ネスト交換子（Phase 0.5）

期待値メモ:
- `[[a(1), a'(1)], a(1)]` = `[[a, a†], a]` = `[1, a]` = **0** （ボゾン交換関係 [a,a†]=1 より）
- `[a(1), [a(1), a'(1)]]` = `[a, [a, a†]]` = `[a, 1]` = **0**

- [X] C3-3 NL 入力: `[[a(1), a'(1)], a(1)] を計算して` → 結果 `0` が表示される（確認済み）
- [X] C3-1 NL 入力: `[[a(1), a'(1)], a(1)]`（サフィックスなし）→ C3-3 と同じ結果 `0`
- [x] C3-2 NL 入力: `[a(1), [a(1), a'(1)]]` → 結果 `0`
- [x] C3-4 CAS カードのサブタイトルが `[[a(1), a'(1)], a(1)] を交換子を計算する` のようにブラケット記法で表示される
  - `bracket_a`/`bracket_b` キーを InterpretResult args に追加（builder の `format_map` は未使用キーを無視）
  - `engine._visible_action` で commutator/anticommutator の両オペランドをブラケット記法で表示
