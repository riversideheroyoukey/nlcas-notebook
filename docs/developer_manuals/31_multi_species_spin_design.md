## 1. 何が足りなかったか

スピン代数は演算子を「成分 × 整数サイト」で表し、異なるサイトは可換として扱う。だから
電子（サイト1）と核（サイト2）の系は**書けたし交換子も回った**：

```
A I·S = A Σ_a S^a_1 S^a_2      交換子・EOM は F-13 以前から動く
```

できなかったのは**評価**である。無限温度トレース `expectation_general` は
全サイトを単一の $x=S(S+1)$ で評価していた。電子 $S=½$ と核 $I=1$ を区別できない。

## 2. 変更点：サイト別の多項式変数

`_site_trace_poly(comps, var)` に変数名を渡せるようにし、
`expectation_general(expr, spins=None)` がサイトごとに変数を分ける。

| `spins` | 挙動 |
|---|---|
| `None`（既定） | 全サイトが共有変数 `x`。**F-13 以前と完全に同じ**（後方互換） |
| `{site: 値}` | 各サイトが自分の `x_i`。値が入っていればそこで評価、`None` なら記号のまま |
| 地図にないサイト | 記号のまま（**共有 `x` には戻さない**）。「サイトは別種だ」と言った以上、どれか一つだけ暗黙に一様へ落ちる方が危ない |

これで

```
⟨I·S⟩       = 0                （各因子がトレースレス）
⟨(I·S)²⟩    = x₁x₂/3            ← x² ではない。ここが F-13
⟨(I·S)²⟩    = 1/2               （S=½, I=1）
```

物理の出どころは常に**2次モーメント**である（1次は消える）：超微細構造の
$\langle H_{\rm hf}^2\rangle$、異核 NMR の Van Vleck 第二モーメント。

## 3. 変数名は `x1`——添字を付けない

これは見た目の趣味ではなく、実測に基づく制約。添字付きの `x_1` は CAS へ渡る途中で
**添字記号 `x(1)` に落ちる**（本プロジェクトの添字規則）。ところが式本体は `x_1` のまま
渡されるので、

```
block([x], ratsimp(subst(x(1)=3/4, x_1 + x_2)))   → 何にもマッチせず、しかし success
```

**代入が黙って効かない。** F-13 の結果は「代入して次へ進む」ために作るものなので、
名前がこの往復を生き延びる必要がある。`site_spin_variable()` が一箇所で決める。

（この代入の非対称——lhs だけ lowering される——は F-13 固有ではない一般の不具合。
open_items「AUDIT-SUBST-INDEXED」に記録した。）

## 4. 結果は「絵」ではなく CAS 値

`Coeff.to_canonical()` を追加した。スピントレースの結果は数か結合定数の多項式、すなわち
**普通の CAS 値**である。`to_latex()` しか無いと表示専用オブジェクトになり、F-9 で塞いだ
のと同じ穴（画面に出ているのに計算に使えない）を作ってしまう。

```
⟨H_hf²⟩ = A²x1x2/3     latex: \frac{1}{3} A^{2} x1 x2     canonical: (A^2*x1*x2)/3
```

`x1` に 3/4 を代入する、という続きが普通に書ける。

**既存の格子系オペ（`energy_moment`／`specific_heat`／スペクトル関数）は今も
`register_dispersion` で canonical=latex のまま**＝表示専用。F-13 の範囲外なので触って
いないが、同じ穴が空いている（open_items F-13（残））。

## 5. 宣言はセッションの状態

`SymbolContext.site_spins`（`{"1": "1/2", "2": "1"}`、永続）。追加キーなので**旧セッション
ファイルは空のまま読め、一様スピンの挙動になる**。

宣言は**タイムラインのステップとして記録する**（`assumption_add`、CAS コマンドなし）。
どのスピンでトレースを取ったかは結果の意味そのものであり、隠れた設定にしてはならない
——セッションは研究ログである。

## 6. NL（日英ルールベース）

- 宣言：「サイト1のスピンを1/2、サイト2のスピンを1とする」/
  "site 1 has spin 1/2 and site 2 has spin 1" / "spin 1/2 on site 1, …"
- 評価：「E1 の期待値」「E1 の2次モーメント」/ "expectation value of E1" /
  "the 2nd moment of E1"

トリガ検出とペア抽出を分ける（F-9 と同じ）。ペア抽出は語順が言語ごとに違うので
`nl_patterns.json` に置き、英語は2通りの語順を**1つの正規表現の択一**として書いて
`site2`/`spin2` 群で受ける。

発火順：`declare_site_spins` はスピン群の先頭（宣言を「スピン H の登録」と読ませない）。
`spin_expectation` は `energy_moment` の**前**——どちらも「モーメント」を見るが、格子側は
模型名を伴い E-id を持たないので衝突しない（`test_lattice_energy_moment_is_not_stolen`）。

## 7. 検証

数値を貼るのではなく**独立な2経路との一致**で確かめる：

1. 全サイトを同じスピンにしたら、一様多項式をその $x$ で評価したものと一致する
   （$S=½,1,3/2,2$）。
2. 全サイト½なら `expectation()` と一致する。これは $S^\pm$ 展開ではなく**パウリ代数で
   書かれた別実装**なので、独立性が高い。

その上で公表値（一重項/三重項的な小さな例、$x_1x_2/3$、$S=½,I=1$ で $1/2$）を置く。
不正なスピン（$1/3$・負）は丸めずに例外。

## 8. 残り

- 格子系オペ（`energy_moment`／`specific_heat`／スペクトル関数）の per-site 化。混合スピン鎖の
  高温展開が要るようになったら。
- 有限温度。現状は無限温度トレースのみ。
- ~~`A-5d`（同一サイト演算子積の未簡約）は共通の制約として残る。~~
  **2026-08-06 に解消。** $S^aS^a=1/4$・$S^aS^b=(i/2)\epsilon_{abc}S^c$ で同一サイト積を畳むと、
  反復交換子の項数が**増大から飽和に変わる**
  （4サイト鎖 2→12→76→474→2758→打ち切り が 2→6→14→21→24→28→30）。
  実装は `spin_algebra._reduce_same_site_half` / `_reducible_sites` / `_all_sites`。

  **ここで設計した `site_spins` は、当初その鍵だと思われたが、鍵だったのは片方だけ**。
  両恒等式は ½ 固有なので「宣言されたサイトだけ畳む」で組んだところ、実測で
  **反跳法（`moments`／`continued_fraction`）の内積は宣言によらず spin-½** と分かった
  （`inner`→`expectation` が spin-½ のトレース、`expectation_general` は記号 $S$ を拒否）。
  その経路で宣言を求めるのは、**計算が既に仮定していることを研究者に宣言させる**ことになる。
  よって経路で分けた:

  | 経路 | 簡約 | 理由 |
  |---|---|---|
  | `moments`／`continued_fraction`（評価） | **常に畳む** | 内積が spin-½ のトレースで、保つべき別のスピンが無い |
  | `commutator`／`nested_commutator`（表示） | **宣言されたサイトのみ** | 一般スピンの $(S^z_2)^2$ を見せる2サイトシナリオが現にある |

  `site_spins` が効くのは表示側である。
