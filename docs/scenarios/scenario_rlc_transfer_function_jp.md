# 実践ループ サンプルシナリオ：RLC 回路の伝達関数（S-e）

実践ループ・シナリオメニュー **S-e（制御・回路）** の詳細化。直列 RLC 回路の微分方程式を
s 領域へ移し、**伝達関数** $H(s)$ を導く。組み込み `laplace` は使わない（不透明な `%at`
初期条件項を避ける）。S-e 専用の操作は一切作らず、**すべて一般操作**（式の登録・E番号参照・
solve・代入）で導く。

**バックエンド:** standard（Maxima）／**ドメイン:** 制御理論（control_theory）。

## 物理的背景

直列 RLC 回路（電荷 $q(t)$、入力電圧 $v(t)$）の運動方程式：

$$L\ddot q + R\dot q + \frac{q}{C} = v.$$

ラプラス変換は線形なので、各項を像に置き換える。未知関数 $q$ の導関数の像は**部分積分**が与える：

$$\int_0^\infty \dot q\,e^{-st}dt = \bigl[q\,e^{-st}\bigr]_0^\infty + s\int_0^\infty q\,e^{-st}dt = sQ(s) - q(0),$$

$\ddot q$ も同様に $s^2Q(s)-sq(0)-\dot q(0)$。ここで $Q(s)=\mathcal L\{q\}=\int_0^\infty q(t)e^{-st}dt$、
$V(s)=\mathcal L\{v\}$（**定義カードで明示**）。よって ODE は

$$L\bigl(s^2Q - s\,q_0 - u_0\bigr) + R\bigl(sQ - q_0\bigr) + \frac{Q}{C} = V,
\qquad q_0 \equiv q(0),\quad u_0 \equiv \dot q(0).$$

**伝達関数**は系そのものの性質で、**ゼロ初期条件** $q_0=u_0=0$ で定義される。これを明示的に
置き、s 領域の式（$Q,V$ の式）を $Q$ について解いて $V$ で割れば

$$Ls^2Q + RsQ + \frac{Q}{C} = V \;\Longrightarrow\; Q = \frac{V}{Ls^2+Rs+1/C}
  \;\Longrightarrow\; H(s) = \frac{Q}{V} = \frac{1}{Ls^2 + Rs + 1/C}.$$

## 導関数の像は「定理」であって、システムが導くものではない

このシナリオは 2026-08-15 に書き直された。以前は `laplace_by_definition` という
**このシナリオのために書かれた操作**が ODE 全体を一度に変換していた。それを削除し、
研究者が変換則そのものを式として書く形に変えた（open_items SCENARIO-MACRO 第7号）。

理由は、部分積分に**選択が無い**ことにある。ラプラス変換の導関数則では $u=e^{-st}$、
$dv=f^{(n)}dt$ が変換の構造で決まっており、一般の部分積分のように $u$/$dv$ の分け方を
選ぶ余地が無い。選択が無いものは「計算」ではなく**定理**であり、定理は研究者が書ける。

書けるなら、システムが持つ理由が無い。マクロを消しても**このシナリオの結果は 1 文字も
変わらない**（テストの期待値がそのまま通ることで確かめてある）。

## 手順と期待値

各段が独立の YOU カード。すべて一般操作で、s 領域に実在する記号（$Q,V$）に対してのみ操作する。

| 段 | 入力（自然言語 / 数式） | 結果 |
|---|---|---|
| 1 | `q を時間依存関数として定義する`／`v を時間依存関数として定義する` | $q,v$ を $t$ の関数として宣言 |
| 2 | `q のラプラス変換を Q とおく`／`v のラプラス変換を V とおく` | 定義カード $Q(s)=\int_0^\infty q(t)e^{-st}dt$, $V(s)=\int_0^\infty v(t)e^{-st}dt$ |
| 3 | `$s Q - q_0$`（数式で登録） | $\mathcal L\{\dot q\}$ ——研究者が書く変換則 |
| 4 | `$s^2 Q - s q_0 - u_0$`（数式で登録） | $\mathcal L\{\ddot q\}$ |
| 5 | `$L E4 + R E3 + Q/C = V$`（数式で登録） | $L(s^2Q - sq_0 - u_0) + R(sQ - q_0) + \dfrac{Q}{C}=V$（**E番号参照**で像を式に組み込む） |
| 6 | `$q_0 = 0$`／`$u_0 = 0$`（数式で登録） | 伝達関数を定義するゼロ初期条件 |
| 7 | `$H = Q/V$`（数式で登録） | $H=Q/V$（伝達関数を定義） |
| 8 | `E5 を Q について解いて` | $Q=\dfrac{CV}{CLs^2+CRs+1}$（初期条件は登録済みなので既に効いている） |
| 9 | `E9 を E8 に代入して` | $H=\dfrac{C}{CLs^2+CRs+1}=\dfrac{1}{Ls^2+Rs+1/C}$ |

## 確認された挙動・注意点

- **像を式に組み込むのは E 番号参照（H-2）。** 段 5 の `L E4 + R E3 + Q/C = V` は、登録済みの
  式を canonical に展開してから登録される。変換則を別の等式として書いて後から代入する筋も
  あるが、**H-1 の定義は登録時に CAS へ送られる**（P2）ので、代入の段に来たときには既に
  適用済みで「対象に含まれていません」と断られる。E 番号参照はその二重適用を避ける。
- **初期条件も同じ理由で「登録すれば効く」。** $q_0=0$ を登録した時点で CAS がそれを持つので、
  段 8 の solve には明示的な代入段が要らない。**代入段を別に置くと拒否される**（上と同型）。
- **伝達関数は一般操作で。** s 領域の式には $q,v$ でなく $Q,V$ しか無い。専用の「伝達関数 q/v」
  操作は数学的に不誠実なので作らない。`$H=Q/V$`（定義）→ `Q について解いて`（solve）→
  `代入` という**実在記号への一般操作**で $H$ を出す。
- **ラプラス変換の定義カードは残る。** $Q$ が $q$ の像であるという**対応**は研究者の命名であり、
  CAS はその名前を知らない（実測：`ilt(Q,s,t)` は $Q$ を定数と読んで $Q\delta(t)$ を返す）。
  この対応は逆変換の結果ラベルが読む（→ 強制振動シナリオ）。CAS 側の名詞形に錨を打って
  対応表を無くす案は open_items **LAPLACE-PAIR-ANCHOR**。
