# 実践ループ サンプルシナリオ：強制振動の初期値問題（ラプラス変換）

外力を受ける調和振動子の**初期値問題**を、$t$ 領域の解まで解く。組み込み `laplace` は
使わない。専用の操作は一切作らず、**すべて一般操作**（定積分・E番号参照・solve・仮定・
逆変換）で書く。

**バックエンド:** standard（Maxima）／**ドメイン:** 微分方程式（differential_equations）。

## なぜこのシナリオが要るか

既存の [RLC 伝達関数（S-e）](scenario_rlc_transfer_function_jp.md) が**一度も通らない**列が
3つある：

| | RLC | 本シナリオ |
|---|---|---|
| 右辺（外力） | 時間依存の**未知関数** $v$ → $V(s)$ | **明示関数** $F_0\sin(\omega t)$ → 定義積分 |
| 初期条件 | **ゼロ**にして消す（伝達関数の定義） | **非ゼロの値**で解く |
| 逆変換 | しない（$s$ 領域で終わる） | $t$ 領域へ**戻して往復を閉じる** |

本シナリオを書いたその日に、この3列がそれぞれ欠陥を出した（末尾参照）。**既存シナリオを
1本増やすより、既存シナリオが通っていない列を探すほうが早い。**

## 物理的背景

外力を受ける無減衰調和振動子（質量 $m$、ばね定数 $k$、外力振幅 $F_0$、駆動角振動数 $\omega$）：

$$m\ddot x + kx = F_0\sin(\omega t),\qquad x(0)=1,\ \dot x(0)=0.$$

ラプラス変換は線形なので各項を像に置き換える。ここで2つの像は**性格が違う**：

- 未知関数 $x$ の2階導関数の像は**部分積分が与える定理**
  $$\int_0^\infty \ddot x\,e^{-st}dt = s^2X(s) - s\,x(0) - \dot x(0),$$
  で、$u=e^{-st}$ が変換の構造で決まっているため**選択の余地が無い**。定理だから研究者が書く。
- 外力の項は**未知関数を含まない明示関数**なので、定義積分そのものが計算できる：
  $$\int_0^\infty \sin(\omega t)\,e^{-st}dt = \frac{\omega}{s^2+\omega^2}.$$
  これは CAS の一般操作（定積分）の仕事。

初期条件（静止状態から単位変位で放す）を置いて $X$ について解き、$m\omega^2 \ne k$（非共鳴）
のもとで逆変換すると、固有振動 $\sqrt{k/m}$ の自由項と駆動振動数 $\omega$ の強制項の和になる。

## 手順と期待値

各段が独立の YOU カード。境界項 $x_0 \equiv x(0)$、$v_0 \equiv \dot x(0)$ は**普通の記号**として
導入するので、任意の値を置いて解ける。

| 段 | 入力（自然言語 / 数式） | 結果 |
|---|---|---|
| 1 | `F_0 をスカラーとする` | $F_0$ を**名前として**登録（添字を成分インデックスにしない） |
| 2 | `x を時間依存関数として定義する` | $x$ を $t$ の関数として宣言 |
| 3 | `x のラプラス変換を X とおく` | 定義カード $X(s)=\int_0^\infty x(t)e^{-st}dt$ |
| 4 | `s > 0 と仮定する`／`\omega > 0 と仮定する` | 定義積分の**収束条件**（仮定を置かないと CAS が符号を聞き返して段が失敗する） |
| 5 | `$\sin(\omega t) e^{-s t}$`（数式で登録） | 定義積分の被積分関数 |
| 6 | `E2 を t で 0 から \infty まで定積分して` | $\displaystyle\int_0^\infty \sin(\omega t)e^{-st}\,dt=\frac{\omega}{s^2+\omega^2}$（**明示関数の像**） |
| 7 | `$m (s^2 X - s x_0 - v_0) + k X = F_0 E3$`（数式で登録） | $m(s^2X - sx_0 - v_0)+kX=\dfrac{F_0\omega}{s^2+\omega^2}$（導関数則は研究者が書き、外力の像は**E番号参照**で組み込む） |
| 8 | `$x_0 = 1$`／`$v_0 = 0$`（数式で登録） | **非ゼロの初期条件**。H-1 の定義は登録時に CAS へ送られるので以降に効く |
| 9 | `E4 を X について解いて` | $X=\dfrac{ms^3+m\omega^2 s+F_0\omega}{ms^4+(m\omega^2+k)s^2+k\omega^2}$ |
| 10 | `m > 0 と仮定する`／`k > 0 と仮定する` | 逆変換の前提（符号が未知だと CAS が対話質問を出す） |
| 11 | `E7 を s から t へ逆ラプラス変換して` | $x(t)=\cos\!\sqrt{\tfrac km}\,t+\dfrac{F_0 m^{3/2}\omega}{m\sqrt k\,(m\omega^2-k)}\sin\!\sqrt{\tfrac km}\,t-\dfrac{F_0\sin(\omega t)}{m\omega^2-k}$（$t=0$ で $x=1$、初期条件と合う） |

## 確認された挙動・注意点

- **像の出どころが2つあり、それは正しい。** 明示関数の像は CAS が計算し（段 6）、導関数の像は
  研究者が書く（段 7）。前者には計算が要り、後者には選択が無い。この線引きが、
  `laplace_by_definition` というマクロを削除できた理由そのもの（open_items SCENARIO-MACRO
  第7号）。
- **収束条件は見える段として置く。** 仮定を置かずに段 6 を実行すると、CAS が
  「Is s positive, negative or zero?」と聞き返し、**その理由を添えて段が失敗する**（セッションは
  生きたまま）。削除したマクロは assume/forget を内部で黙って行っていた——共有コードに
  隠れたモデリング選択を焼き込まないという原則からも、明示的な段のほうが正しい。
- **初期条件は「登録すれば効く」。** $x_0=1$ を登録した時点で CAS がそれを持つので、段 9 の
  solve に明示的な代入段は要らない。**代入段を別に置くと「対象に含まれていません」と
  断られる**（既に適用済みだから。E番号参照を使う理由も同じ）。
- **逆変換には符号の仮定が要る。** $m,k,\omega$ の符号が未知だと Maxima が対話質問を出し、
  操作は「確認を求められた」失敗として返る。物理的に正であることを**明示的な仮定の段**として
  置くのが正道で、共有コードに既定値を焼き込まない。
- **非共鳴の前提。** 上の解は $m\omega^2 \ne k$ を前提とする。$\omega^2=k/m$ では分母が消え、
  共鳴（$t\sin\omega t$ 型の増大解）は別に扱う必要がある。
- **$F_0$ は名前として宣言する。** 宣言しないと未宣言添字の規則で $F(0)$ に降り、
  同じ量が1つの文書に $F_0$ と $F(0)$ の2綴りで現れる。
- **逆変換の結果に $x(t)=$ のラベルが付く。** これは段 3 の定義カードが $X \leftrightarrow x$ の
  対応を記録しているため。対応そのものは CAS も持っているが（`ilt(laplace(x(t),t,s),s,t)` は
  $x(t)$ を返す）、**研究者が付けた名前 $X$ は知らない**（`ilt(X,s,t)` → $X\delta(t)$）。
  CAS 側の名詞形に錨を打って対応表を無くす案は open_items **LAPLACE-PAIR-ANCHOR**。

## このシナリオが見つけた欠陥（2026-08-13）

書いたその日に、**成功として返る silent-wrong** を4件出した。①②③は根治済み、
④は規模が大きいので起票のみ。

1. **外力の項が変換されなかった**。線形性の分解が**未知関数を含む項しか置換せず、
   残りを素通し**していたため、$t$ 領域の項が $s$ 領域の方程式に居座った式が成功として
   返っていた。RLC の右辺は未知関数 $v$ なので踏まない。**この欠陥があった分解は
   2026-08-15 にマクロごと削除された**——素通しできる経路自体がもう無い。
2. **$x_{ic1}$ が二重下付きになり `.tex` が組版できなかった**
   （`notebook/runtime/maxima_backend_handler.py`）。Maxima の `tex1` は末尾の数字を
   切り離して `{\it x\_ic}_{1}` と書くため、展開すると `x_{ic}_{1}` — LaTeX のハードエラー。
   `k_B1` や `a_b2` でも同じで、ラプラスに限らない一般の欠陥だった。
3. **逆変換が方程式の左辺まで変換した**（`notebook/engine.py`）。
   $X=\cdots$ に `ilt` を掛けると Maxima は $X$ を定数と読み、**$X\delta(t)=\cdots$** を
   返す。素の記号左辺を剥がす判定が3つの別々の集合で書かれており、変換系はそのどれにも
   入っていなかった（残る5操作は open_items EQ-SOURCE-BARE-LHS）。
4. **英語の「inverse Laplace transform」が順変換に解決された**（2026-08-15 根治、下記）。
