# 実践ループ シナリオ：スピン依存の基底で行列要素を定義する

> 2026-08-09 実施。場の演算子を**スピン依存の基底**で展開したときに現れる係数——
> 1体行列要素と2体行列要素——を、**全空間積分の「定義」のまま**ノートに置けることを確認する。
> 対になる[スピンありの1次摂動シナリオ](scenario_spinful_perturbation_jp.md)の前半にあたる。

**バックエンド:** Maxima／**ドメイン:** 量子力学（quantum_mechanics）。

### なぜこれが確認に値するのか

場の演算子をスピン依存の基底で展開すると

$$\hat\psi_\sigma(\mathbf x)=\sum_m \varphi_{m\sigma}(\mathbf x)\,\hat c_{m\sigma}$$

となり、ハミルトニアンの係数は**全空間積分で定義される**:

$$h_{m\sigma,n\sigma'}=\int\! d^3x\;\varphi^*_{m\sigma}(\mathbf x)\,\hat T(\mathbf x)\,\varphi_{n\sigma'}(\mathbf x)$$

ここが要点で、**この積分は評価するものではない**。基底 $\varphi_{m\sigma}$ は任意だから、
評価しようがない。積分そのものが $h_{m\sigma,n\sigma'}$ の定義であり、以降の計算は
この係数を**記号として**運ぶ。

つまりノートに求められるのは「計算できること」ではなく、**定義として置けて、
書いたとおりに表示され、後で使えること**である。2026-08-08 まではそれができなかった:

- $\int d^3x$ は1変数の積分にしか降ろせず、**`(d^3·int·x·f(x))/(8π³)` という積として
  黙って計算されていた**（open_items B-10 ②-g）
- 直したあとも、**展開が評価を兼ねていると落ちる**。実測すると、任意基底の行列要素を
  全空間で評価させた Maxima は「簡約できない」のではなく **`ok=False` の空応答**を返す
  （答えようのない収束の問いを投げてくる）。だから展開は名詞形で**保持**し、評価は
  別の指示にした

本シナリオは、その両方が効いていることを**行列要素という実物**で確認する。

### 物理の筋

1. 直交規格化 $\int d^3x\,\varphi^*_{m\sigma}\varphi_{n\sigma'}$ を書き、成分に展開する
2. 1体行列要素 $h_{m\sigma,n\sigma'}$ を定義する（H-1 の等式形）
3. 成分に展開する → デカルト3成分の反復積分になる
4. **評価を指示しても定義のまま残る**ことを確認する（任意基底なので評価対象ではない）
5. 2体行列要素 $V$ を定義する → **6次元**（$d^3x\,d^3y$）の積分が成分に開く

スピンは終始 $\varphi_{m,s}$ の**第2添字**として運ばれる。モード $m$ とスピン $s$ が
区切られたまま表示されることが、そのまま再入力できる条件でもある。

## 確認された挙動・注意点

**展開と評価は別の指示である。** これは好みではなく必須で、実測（2026-08-08）すると
任意基底の行列要素を全空間で評価させた Maxima は `ok=False` の空応答を返す
（答えようのない収束の問い）。展開が評価を兼ねていたら、このシナリオは ST-2 で落ちる。

**範囲を書かなくても全空間。** 体積測度は不定積分ではない。不定積分として読むと
$\pi^{3/2}\mathrm{erf}(x_x)\mathrm{erf}(x_y)\mathrm{erf}(x_z)/8$ のように**積分変数が残った答え**が
返り、$\pi^{3/2}$ を含むので見落としやすい。この既定を安全に入れられるのは**保持するから**で、
意味として記録するだけで評価は試みない。

**複素共役は物理の綴りで入る。** 星を関数の前に置く $\varphi^*_{m,s}(x)$ で書ける。
2026-08-09 まではこれが「多重添字の適用形」として断られていた——星を添字と数えていた
ためで、単一添字の $\psi^*_n(x)$ でも同じ拒否になっていた。同時に、中括弧付きの綴り
（`^{\ast}`・`^{*}`——TeX エディタが吐く形であり、**このシステム自身の表示が返す形**）は
拒否されずに `psi^(\ast)*(x)` へ黙って化けていた。つまり**表示を打ち直すと別物になる**
状態だった。いまは `^*`・`^{*}`・`^{\ast}`・`^\ast`・`^{\star}`・後置の `f(x)^*` が
すべて同じ canonical に落ち、CAS には `conjugate(...)` として届く。

**共役の有無で別物にならないこと**も条件で、`\varphi^*_{m,s}(x)` と `\varphi_{m,s}(x)` は
同じ `phim, s (reference omitted from the public snapshot)` を指す（星の付いた側だけ添字の読みを決め直すと、内積の2つの因子が
永久に組にならない）。`\overline{f(x)}` も共役として通る——ただし単独記号の
`\overline{z}` は H-1 の命名規約どおり `z_bar` という**名前**のままで、そこは変えていない。

**1体演算子の綴り。** `\hat{h}(x)` は `h_{hat}(x)` と表示されるので使っていない
（適用された下付きが名前に畳まれるため）。ここでは係数 $h$ と衝突しない `T` を使い、
運動＋外場をまとめた1体演算子と読む。

**この続き。** 係数が定義できたら、演算子代数は Julia セッションの仕事になる
（バックエンドはセッション固定＝原則#6）。[スピンありの1次摂動シナリオ](scenario_spinful_perturbation_jp.md)へ。

**確認日:** 2026-08-09（実機 Maxima、ST-1〜4 完走）。
