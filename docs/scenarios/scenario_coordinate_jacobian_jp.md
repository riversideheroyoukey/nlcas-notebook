# 実践ループ サンプルシナリオ：定積分の変数変換（ヤコビアン）

実践ループ・シナリオメニュー **S-o（解析／体積積分）** の詳細化。**範囲つき定積分そのもの**を
**極座標・球座標などへ変数変換**し、被積分関数だけでなく**積分範囲も新変数のものへ書き換えられた
定積分**が表示され、評価して数値が得られることを確認する。

**バックエンド:** standard（Maxima）／**ドメイン:** 電磁気（electromagnetism）。

> **このシナリオの肝＝定積分オブジェクトの 4 段ワークフロー（すべて LLM 非依存）。**
>
> 1. **範囲つき定積分を表示専用の未評価オブジェクトとして与える** — 領域述語
>    `x^2+y^2<=1 の領域で x^2+y^2 を定積分` か LaTeX 記法 `\int_0^1 \int_0^1 (x+y)\,dx\,dy`。
>    **この時点では CAS に渡さない**（積分領域を式から抽出して保持するだけ）。
> 2. **変数変換を指示する** — `… を x,y から r,theta へ x=r*cos(theta), y=r*sin(theta) で変数変換して`。
> 3. **新しい範囲つき定積分が組み立てられ表示される** — 被積分関数 $f\circ T\cdot|J|$ ＋
>    **新しい積分範囲**。標準座標変換（極座標×円板、球座標×球）の新範囲は**自動算出**。
>    自動算出できない場合は、新変数指定に範囲を添える（`r:0..1, theta:0..2π`）か LLM 提案を使う。
> 4. **`この定積分を評価して`** で反復積分を実行し数値を得る（極座標·単位円板 $\to\pi/2$、
>    球座標·単位球の体積 $\to 4\pi/3$）。
>
> 単一の被積分関数だけを変換する旧来の経路（`change_integration_variables` → `簡約` → 単変数 `定積分`）も
> ビルディングブロックとして残っており、下記「単項経路」に記す。

## 物理的背景

多変数積分の変数変換 $\int f\,dV$ では、被積分関数を新変数で表したものに**ヤコビアン行列式**
$\bigl|\partial(\text{旧})/\partial(\text{新})\bigr|$ を掛ける。

- **2 次元・極座標** $(x,y)\to(r,\theta)$：$x=r\cos\theta,\ y=r\sin\theta$、$|J|=r$。
  よって $\displaystyle\iint (x^2+y^2)\,dx\,dy = \iint r^2\cdot r\,dr\,d\theta = \iint r^3\,dr\,d\theta$。
- **3 次元・球座標** $(x,y,z)\to(r,\theta,\phi)$：
  $x=r\sin\theta\cos\phi,\ y=r\sin\theta\sin\phi,\ z=r\cos\theta$、$|J|=r^2\sin\theta$。
  よって体積要素 $dV = r^2\sin\theta\,dr\,d\theta\,d\phi$。

## セッション設定・記号宣言

- モード **standard（Maxima）**、ドメイン **電磁気**。
- 変換式は**旧変数と同じ順序**でカンマ区切り（`atan2(v,u)` のような関数引数のカンマは保護される）。
- 新変数指定に範囲を添える形 `r:0..1, theta:0..2π` も可（`π`／`\pi` は `%pi` に正規化）。

## 手順と期待値（定積分オブジェクト・ワークフロー）

### 1. 極座標：単位円板上の $\iint(x^2+y^2)\,dx\,dy$

| ステップ | 入力（自然言語） | 期待される表示 |
|---|---|---|
| 1a 定義 | `x^2+y^2<=1 の領域で x^2+y^2 を定積分` | $\iint_{x^2+y^2\le 1}(x^2+y^2)\,dx\,dy$（**未評価・表示専用**） |
| 1b 変数変換 | `E1 を x,y から r,theta へ x=r*cos(theta), y=r*sin(theta) で変数変換して` | $\int_{0}^{2\pi}\!\!\int_{0}^{1} r^3\,dr\,d\theta$（被積分関数·\|J\|＋**新範囲を自動算出**） |
| 1c 評価 | `この定積分を評価して` | $\displaystyle\int_{0}^{2\pi}\!\!\int_{0}^{1} r^3\,dr\,d\theta=\frac{\pi}{2}$ |

### 2. 球座標：単位球の体積

| ステップ | 入力（自然言語） | 期待される表示 |
|---|---|---|
| 2a 定義 | `x^2+y^2+z^2<=1 の領域で 1 を定積分` | $\iiint_{x^2+y^2+z^2\le 1}(1)\,dx\,dy\,dz$（未評価） |
| 2b 変数変換 | `E4 を x,y,z から r,theta,phi へ x=r*sin(theta)*cos(phi), y=r*sin(theta)*sin(phi), z=r*cos(theta) で変数変換して` | $\int_{0}^{2\pi}\!\!\int_{0}^{\pi}\!\!\int_{0}^{1} r^2\sin\theta\,dr\,d\theta\,d\phi$ |
| 2c 評価 | `この定積分を評価して` | $=\dfrac{4\pi}{3}$（単位球の体積） |

### 3. 一般ヤコビアン（LaTeX 入力＋利用者指定の新範囲）

| ステップ | 入力（自然言語） | 期待される表示 |
|---|---|---|
| 3a 定義 | `\int_{0}^{1} \int_{0}^{1} (x+y) \, dx \, dy` | $\int_{0}^{1}\!\!\int_{0}^{1}(x+y)\,dx\,dy$（未評価） |
| 3b 変数変換 | `E7 を x,y から u:0..1, v:0..1 へ x=2*u+v, y=u+3*v で変数変換して` | $\int_{0}^{1}\!\!\int_{0}^{1}(15u+20v)\,dv\,du$（$\det J=5$ を挿入、**新範囲は利用者指定**） |
| 3c 評価 | `この定積分を評価して` | $=\dfrac{35}{2}$ |

> **新範囲の算出方針:** 標準座標変換×標準領域（極座標×円板、球座標×球）はテーブルで自動算出。
> 当てはまらない一般変換は、新変数指定に範囲を添える（`u:0..1, v:0..1`）か、LLM 提案を使う。
> 測度は $\det J$（標準座標の正方向順では $r,\ r^2\sin\theta>0$ なので符号は結果を誤らせない）。

### 単項経路（ビルディングブロック）

被積分関数だけを変換したいときは、定積分オブジェクトを介さず直接：
`x^2+y^2 を x,y から r,theta へ x=r*cos(theta), y=r*sin(theta) で変数変換して` → 生 Jacobian 積 →
`簡約して` → $r^3$。単変数の定積分は `… を r で 0 から 1 まで定積分して`。

## 確認された挙動・注意点

- **`change_integration_variables` 自体は正しい**（Jacobian 行列式は正確）。両バックエンドで生 Jacobian 積は一致。
  ただし返すのは**未簡約の生 Jacobian 積**で、教科書形にはならない。
- **`簡約して`（`simplify`）一語で両バックエンド共通**（CAS 構文・差異を意識しなくてよい＝Core Principle #1）。
  `三角簡約して`（`trig_simplify`）も同じ結果。

  | バックエンド | キーワード | 極座標 | 球座標 |
  |---|---|---|---|
  | **Maxima** | `簡約`／`三角簡約` | $r^3$ ✓ | $r^2\sin\theta$ ✓ |
  | **Julia** | `簡約`／`三角簡約` | $r^3$ ✓ | $r^2\sin\theta$ だが**未簡約**（$\sin^2\phi+\cos^2\phi$ が残る）|

  > **キーワード統一の経緯（2026-06-22）:** 当初は Maxima の `簡約`(simplify) が `ratsimp` のみで trig 非適用、
  > Julia の `簡約` は trig 適用、Maxima の `三角簡約`(trig_simplify) のみが trig 適用、と**バックエンドで
  > 効くキーワードが食い違い CAS を意識させた**。根治：Maxima `simplify` を `trigsimp(ratsimp(...))` に、
  > Julia `trig_simplify` を `simplify` にマップ（schema に julia_full 追加）。これで `簡約`／`三角簡約`
  > どちらも両バックエンドで $\sin^2+\cos^2=1$ を適用する。

- **残る差は CAS 能力（キーワードではない）:** Julia（Symbolics.jl）は **3 次元・球座標を完全には畳めず**
  $r^2\sin\theta\cdot\sin^2\phi + r^2\sin^3\theta\cdot\cos^2\phi + r^2\sin\theta\cos^2\theta\cdot\cos^2\phi$
  （$=r^2\sin\theta$ だが未簡約）で止まる（`簡約`×2・`factor` でも不変）。**完全 clean な $r^2\sin\theta$ は
  Maxima のみ。**（Maxima 側で `trig_reduce`/`rational_simplify` を**個別に**呼ぶと畳みきれないが、
  統一後の `簡約`／`三角簡約` は正しく畳む。）

**確認日:** 2026-06-22（実機で確認：両バックエンドとも `簡約`/`三角簡約` → 極 $r^3$；
Maxima 球 $r^2\sin\theta$（clean）、Julia 球は $r^2\sin\theta$ の未簡約形）。
