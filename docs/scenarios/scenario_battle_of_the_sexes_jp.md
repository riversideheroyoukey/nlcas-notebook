# 実践ループ サンプルシナリオ：「夫婦の争い」の純戦略・混合戦略均衡

古典的な2人ゲーム「夫婦の争い」（Battle of the Sexes）の純戦略ナッシュ均衡と
混合戦略均衡を求める。

**バックエンド:** standard（Maxima）／**ドメイン:** ゲーム理論（game_theory）。

## 手順と期待値

$A$ はプレイヤー1（行）の利得、$B$ はプレイヤー2（列）の利得。行1・列1 が「オペラ」、
行2・列2 が「バレエ」に当たる。

| 段 | 入力（自然言語 / 数式） | 結果 |
|---|---|---|
| 1 | `$A = [2, 0; 0, 1]$` | プレイヤー1の利得行列 |
| 2 | `$B = [1, 0; 0, 2]$` | プレイヤー2の利得行列 |
| 3 | `E1 と E2 の純戦略ナッシュ均衡を求めて` | $\{(1,1),(2,2)\}$ —— 両者が同じ催しを選ぶ2つの純戦略均衡 |
| 4 | `$2 q + 0 (1-q) = 0 q + 1 (1-q)$` | **プレイヤー1の無差別条件を研究者が書く。** 相手が確率 $q$ で列1 を選ぶとき、行1 と行2 の期待利得が等しい |
| 5 | `E4 を q について解いて` | $q = \dfrac{1}{3}$ |
| 6 | `$1 p + 0 (1-p) = 0 p + 2 (1-p)$` | プレイヤー2の無差別条件（自分が確率 $p$ で行1 を選ぶ相手に対して） |
| 7 | `E6 を p について解いて` | $p = \dfrac{2}{3}$ |

混合戦略均衡は $(p,q)=(2/3,\,1/3)$。マクロの出した値と一致する（削除前に実測）。

## 確認された挙動・注意点

- **無差別条件は期待利得の等式であり、ゲーム理論の内容である。** 行列成分から
  システムが組み立てる必要はない。研究者が $2q = 1-q$ に相当する式を書けばよく、
  書いた式がそのままタイムラインに残るぶん、**どの利得を比べているのかが読める**。
- **マクロが持っていた防御的な書き方は不要になった。** マクロは結果が
  `q = <式>` という裸の形に潰れると H-1 の P2 が CAS 側で `q` を束縛してしまうため、
  わざと `lhs - rhs = 0` の形で組み立てていた。根本原因側のガード
  （`run_operation` の結果は P2 束縛しない、BP-7）は残っており、
  `tests/test_game_theory.py::test_bp7_root_cause_operation_result_never_p2_binds`
  がそれを押さえている——**マクロの回避策を消しても、根治のほうは残る。**
- **英語版の段 3 は本来の綴りに戻した（2026-08-15）。** それまでは
  `pure_nash_equilibria of E1 and E2` と**操作名そのもの**を打つほかなかった。
  この操作の EN 別名は3つとも複数語で、別名走査がトークン単位だったため
  **英語からはこの操作が存在しないのと同じ**状態にあった
  （open_items **EN-ALIAS-MULTIWORD**、根治済み——走査は句を、長いものから照合する）。
