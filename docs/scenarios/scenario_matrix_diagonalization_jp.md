# 実践ループ サンプルシナリオ：行列の対角化（固有値・固有ベクトル → P⁻¹AP）

実践ループ・シナリオメニュー **S-i（線形代数）** の詳細化。2×2 対称行列について、
**固有値・固有ベクトル**を求め、固有ベクトルから変換行列 $P$ を作り、
**相似変換 $P^{-1}AP$ が固有値を並べた対角行列**になることを確認する。

**バックエンド:** standard（Maxima）／**ドメイン:** 線形代数（linear_algebra）。

> 行列操作（固有値・固有ベクトル・逆行列・行列積・行列式）は Maxima・Julia
> 両バックエンドで動作する。Julia（第二量子化セッション）では基底変換などで同じ操作を使う。

## 物理・数学的背景

対称行列
$$A = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}$$
の固有値は $\lambda = 1, 3$、対応する固有ベクトルは $(1,-1)^\top,\ (1,1)^\top$。
**正規化した**固有ベクトルを列に並べた直交行列
$$P = \frac{1}{\sqrt{2}}\begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}$$
で相似変換すると（$P$ は直交なので $P^{-1} = P^\top$）
$$P^{-1} A P = \begin{pmatrix} 3 & 0 \\ 0 & 1 \end{pmatrix}$$
と対角化される（対角成分が固有値）。

## 行列の入力記法

2 次元の数表は **`[a, b; c, d]`**（`;` が行区切り、`,` が列区切り）で入力する。
**TeX の書法も同じものとして読む**（2026-09-10、TEX-MATRIX-INPUT）——
`\begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}` は `[2, 1; 1, 2]` と同じ行列に
なる。上の背景に書いた式を**そのままコピーして打てる**、ということである
（`bmatrix`・`matrix`・`Bmatrix`・`smallmatrix`・`array`、plain TeX の
`\pmatrix{…}` も同じ。縦棒の `\begin{vmatrix}` は**行列式**）。

- `;` **あり** → 行列（`[2, 1; 1, 2]` は $2\times2$ 行列）。
- `;` **なし** → 交換子・リスト（`[A, B]` は交換子）。

表示は `\begin{pmatrix}` で数表としてレンダリングされる。内部の canonical は CAS 形式
（Maxima `matrix([2,1],[1,2])` / Julia `[2 1; 1 2]`）に正規化される。

## 入力ステップ

### ステップ 1：行列の登録と固有値・固有ベクトル

```
A = [2, 1; 1, 2]                → E1
E1 の固有値を求めて                → E2 = [固有値 1, 3]
E1 の固有ベクトルを求めて             → E3 = [固有ベクトル (1,-1), (1,1)]
```

### ステップ 2：変換行列 P と対角化

正規化した固有ベクトルを列に並べた直交変換行列 $P$ は **`対角化`** で自動生成できる
（手で組む必要はない）。固有値を並べた対角行列 $D$ は **`対角行列を求めて`** で直接得られる。

```
E1 を対角化して                  → E4 = P     （正規化固有ベクトルを列に並べた直交行列）
E1 の対角行列を求めて              → E5 = diag(3, 1)
E4 の逆行列を求めて                → E6 = P⁻¹
E6 と E1 の行列積を求めて           → E7 = P⁻¹A
E7 と E4 の行列積を求めて           → E8 = P⁻¹AP = diag(3, 1)
```

$P$ は直交行列なので $P^{-1}=P^\top$。E8 が対角行列 $\mathrm{diag}(3,1)$ になり、
ステップ 2 の $D$（E5）と一致して **対角成分が固有値**であることを確認できる。

> `対角化` は固有ベクトルを正規化して列に並べた**直交行列** $P$ を返す（Maxima・Julia 共通）。
> `対角行列を求めて`（`diagonal_matrix`）は固有値を並べた対角行列 $D$ を返す。
> $P^{-1}AP = D$ が成り立つ（固有値の並び順は固有値・固有ベクトルの算出順に従う）。

## カバレッジ

- **対角化ワークフロー**（固有値 → 固有ベクトル → 直交 P / 対角 D → P⁻¹AP = D）。
- 行列操作 `eigenvalues` / `eigenvectors` / `diagonalize` / `diagonal_matrix`
  / `inverse_matrix` / `matrix_multiply`（ルールベース、LLM 非経由）。
- 2 次元行列リテラル `[a, b; c, d]`（`;` = 行列、無 = 交換子）と pmatrix 表示。
- バックエンド：Maxima（Julia でも同一操作が動作）。
