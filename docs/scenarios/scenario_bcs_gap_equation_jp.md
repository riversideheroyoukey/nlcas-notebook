# 実践ループ シナリオ S-c：BCS ギャップ方程式（Julia → Maxima のスカラー handoff）

> 2026-08-03 実施。[scenario_bcs_hamiltonian_jp.md](scenario_bcs_hamiltonian_jp.md)（演算子部）の
> **続き**にあたる。あちらが Bogoliubov 条件で終わるのに対し、こちらは異常平均まで進んで
> **セッション境界を越え**、Maxima 側で BCS 閉形式 $\Delta=\omega_D/\sinh\frac{1}{N_0V}$ に到達する。

**バックエンド:** Julia（QuantumAlgebra.jl）→ **Maxima**（handoff 先）／**ドメイン:** 凝縮系物理。

### なぜ2つのセッションに分かれるのか

演算子代数は QuantumAlgebra の仕事、$(k,i\omega_n)$ 空間のスカラー代数は Maxima の仕事で、
**バックエンドはセッション作成時に固定される**（Core Principle #6）。演算子を終えた計算は
だから境界を越える。越え方は **fork であって切り替えではない**——生の状態は何も持ち越さず、
渡るのは利用者自身の書式と、それを渡し先で establish し直すための宣言だけで、渡し先の
セッションは全ステップを実際に実行する（[docs/34 §5](../developer_manuals/34_field_operators_pair_representation_and_scalar_handoff.md)）。

### 物理の筋

1. 平均場 BCS ハミルトニアンを Bogoliubov 変換で対角化する（＝演算子部、S-c 前半）
2. 異常平均 $\langle c_{-k\downarrow}c_{k\uparrow}\rangle = \dfrac{uv}{(u^2+v^2)^2}$ を得る
   ——ここで**演算子代数は終わり**、以降は c 数の話
3. ギャップの自己無撞着条件 $\Delta = V\sum_k \langle c_{-k\downarrow}c_{k\uparrow}\rangle$ を
   連続極限で $1 = N_0V\displaystyle\int_0^{\omega_D}\frac{d\xi}{\sqrt{\xi^2+\Delta^2}}$ と書く
4. 積分を実行して $\mathrm{asinh}\dfrac{\omega_D}{\Delta}$、$\Delta$ について解いて
   $\Delta = \dfrac{\omega_D}{\sinh\frac{1}{N_0V}}$

3・4 は Maxima の領分。2 までが Julia の領分。**その境目が handoff。**

## 確認された挙動・注意点

**このシナリオは走らせた初回に2件の欠陥を出した。1件目は S-c を完全に止めていた。**

| # | 症状 | 真因 | 修正 |
|---|---|---|---|
| 1 | `E14 を Maxima セッションに渡して` が「E14 には演算子（c）が残っている」と**拒否**。S-c が完走できない | 真空期待値の結果は `c(-k,d) c(k,u) = uv/(u²+v²)²` という**ラベル付き等式**で、左辺は「何の期待値か」を示すラベル。演算子検査が行全体を走査して左辺の `c` を見つけていた。**期待値は定義上 c 数**なので、この機構が渡すために作られた当のものを追い返していた | 検査対象を**値（右辺）**にした（`split_export_form`）。検査の緩和ではない——値に演算子があれば従来どおり拒否する。演算子ラベルは登録せず、渡し先のメモに「〜の値」として残す |
| 2 | 渡りの照合が「⚠ 渡した式が元の式と一致しません（`_nb_E16` vs `u, v`）」と**誤警報** | 照合の元側に `source_canonical` を使っていたが、Julia の結果のそれは不透明ハンドル `_nb_E16`。**照合できないだけ**なのに「不一致」と報告していた | 元側の LaTeX を**元のバックエンドのハンドラで**読んだ結果と突き合わせる（`source_value_canonical`）。2つの独立した読み（元ハンドラ vs 渡し先ハンドラ）の一致こそ、この検査が見たい往復そのもの。ハンドルしか無い場合は `not_checkable` と言う（不一致とは言わない） |

**「照合できない」と「一致しない」は違う。** 設計文書（docs/34 §5.3）は「検証できない場合を
一致と書かない」と決めていたが、**その裏返しも同じくらい重要**だった——正しい結果を
「一致しません」と告げるのは、黙っているより悪い。

**手作業の測定では出なかった。** 2026-07-31 の測定（docs/34 §6）は手で転記したので、
演算子検査も値照合も通っていない。**機構化したものは機構経由で走らせないと確かめたことにならない。**

**確認日:** 2026-08-03（実機 Julia + Maxima、ST-1〜12 完走）。

## generator コマンド（この `scenario` ブロックが生成の単一ソース）

> **注:** generator は1シナリオ＝1セッションを生成するため、このブロックは **Julia 側（ST-1〜9）
> まで**を実行する。渡し先セッションは handoff が別ファイルとして書き出すので、ST-10〜12 は
> そのファイルを開いて続ける（上の表のとおり）。

```scenario domain=condensed_matter
@note: BCSハミルトニアンを組み立てるための演算子・パラメータを準備する。$c$ は運動量 $k$・スピン $\sigma$（$u=\uparrow$, $d=\downarrow$）を持つ電子の消滅演算子、$g$ は Bogoliubov 準粒子の消滅演算子。$u, v$ は変換係数、$\xi$ は運動エネルギー、$\Delta$ は超伝導ギャップ。
c を電子の消滅演算子として定義して
g をフェルミオン演算子として定義して
u, v をスカラーパラメータとして定義して
xi, Delta をスカラーパラメータとして定義して
@note: 平均場BCSハミルトニアンを登録する。
H_BCS = xi * (c'(k,u) c(k,u) + c'(-k,d) c(-k,d)) + Delta * (c'(k,u) c'(-k,d) + c(-k,d) c(k,u))
@note: 運動方程式で $c(k,u)$ が H_BCS とどう結びついているかを確認する。
c(k,u) の Heisenberg 方程式 E1
@note: Bogoliubov 変換を Nambu スピノル形式の4本まとめて定義する。
g(k,u) = u * c(k,u) - v * c'(-k,d)
g(-k,d) = u * c(-k,d) + v * c'(k,u)
g'(k,u) = u * c'(k,u) - v * c(-k,d)
g'(-k,d) = u * c'(-k,d) + v * c(k,u)
@note: 4本を電子演算子について解き直し（逆変換）、準粒子演算子で電子演算子を表す。
E3, E4, E5, E6 を c(k,u), c(-k,d), c'(k,u), c'(-k,d) について逆変換して
@note: 逆変換をハミルトニアンへ代入する。対生成項の係数がゼロになるよう $u,v$ を選ぶのが Bogoliubov 条件。
E1 の c(k,u) に E7 を、c(-k,d) に E8 を代入する
@note: ここからギャップ方程式へ向かう。クーパー対の異常平均 $\langle c_{-k\downarrow}c_{k\uparrow}\rangle$ を求めるため、まず対の積を式として登録する。
c(-k,d) c(k,u)
@note: 準粒子基底へ移す。
E12 の c(k,u) に E7 を、c(-k,d) に E8 を代入する
@note: 準粒子の真空（＝BCS基底状態）での期待値を取る。ここで演算子代数は終わり、以降は c 数の計算になる。
@op: vacuum_expectation {"expr": "E13"}
@note: 演算子を終えたので、残りのスカラー代数は Maxima の領分。セッション境界を越える（fork であって切り替えではない——このセッションはそのまま残り、渡し先は新しいファイルになる）。渡るのは右辺の値と、それを渡し先で establish し直すための宣言（符号込み）。左辺の演算子ラベルはスカラー CAS で意味を持たないので、値が「何の期待値か」は渡し先のメモに残る。
E14 を Maxima セッションに渡して
```
