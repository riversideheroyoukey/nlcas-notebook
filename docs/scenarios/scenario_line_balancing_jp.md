# 実践ループ サンプルシナリオ：ラインバランシング（最小工程数・ライン効率）

実践ループ・シナリオメニュー **S-u（生産最適化）** の詳細化。作業時間の総和 $T$
（サイクルタイム $c$ の生産ライン）から、必要な最小工程数 $n=\lceil T/c\rceil$（天井関数）
とライン効率 $\eta=T/(nc)$、バランス遅れ $1-\eta$ を求める。**算術・代入**だけで完結する
小規模で分かりやすいシナリオ。

**バックエンド:** standard（Maxima）／**ドメイン:** 生産最適化（production_optimization）。

## モデルの背景

ライン生産方式で、全作業要素の所要時間の総和が $T$、サイクルタイム（1工程あたりの
許容時間）が $c$ のとき：

- 最小工程数（ステーション数）: $n=\left\lceil\dfrac{T}{c}\right\rceil$
  （$T/c$ 未満には作れないので天井関数で切り上げ）
- ライン効率: $\eta=\dfrac{T}{nc}$（理想的な合計稼働時間 $T$ に対する実際の総稼働可能時間 $nc$ の比）
- バランス遅れ（idle 率）: $1-\eta$

具体例（$T=88$、$c=15$）: $n=\lceil88/15\rceil=\lceil5.867\rceil=6$、
$\eta=88/(6\times15)=88/90=44/45\approx0.978$、バランス遅れ $=1/45\approx0.022$。

## セッション設定・記号

- モード **standard（Maxima）**、ドメイン **生産最適化**。
- $T,c,n,\eta$ は自由変数。天井関数は Maxima の組み込み関数 `ceiling(...)` を使う
  （`ceil` ではない — 既知関数名リストの表記に合わせる）。

## 入力ステップ

### ステップ 1・2：モデルの定義（H-1）

```
n = ceiling(T / c)
eta = T / (n c)
```

**期待する出力:** E1 $=n=\lceil T/c\rceil$、E2 $=\eta=T/(nc)$（それぞれ H-1 の named
quantity として登録。「n」「eta」は以降の式でも記号として使い続けられる）。

### ステップ 3・4：具体値（$T=88,\ c=15$）を代入して工程数を確定

```
E1 の T に 88 を代入して
E3 の c に 15 を代入して
```

**期待する出力:** E3 $=n=\lceil88/c\rceil$、E4 $=n=6$。

### ステップ 5・6：同じ具体値を効率の式へ代入

```
E2 の T に 88 を代入して
E5 の c に 15 を代入して
```

**期待する出力:** E5 $=\eta=\dfrac{44}{3c}$、E6 $=\eta=\dfrac{44}{45}$。

> ステップ5の時点で分母がすでに $3c$（$n=6$ が織り込まれた形）になっている点に注意 —
> 下記「確認された挙動」参照。

### ステップ 7：バランス遅れ（H-2 の式参照展開）

```
d = 1 - E6
```

**期待する出力:** E7 $=d=\dfrac{1}{45}$（$1-\eta$ を $E6$ の値に展開して直接計算）。

## 確認ポイント

- 天井関数 `ceiling` が Maxima の組み込みとして正しく評価される（$\lceil5.867\rceil=6$）。
- H-2（式参照展開）により、`d = 1 - E6` のような**式番号を直接埋め込んだ新しい式**が
  そのまま計算まで完了する。

## 確認された挙動・注意点

- **H-1 の P2 自動代入は、後続の別の式にも自動的に伝播する。** `n = ceiling(T/c)` を
  H-1 で登録すると、Maxima 側にも `n : ceiling(T/c)$` として送られる（P2）。この後、
  `n` を含む別の式（`eta = T / (n c)`）で `T` を代入する操作を行うと、Maxima は
  `n` を評価する際に**その時点で最新の `n` の定義（すでに `n=6` まで確定済みなら
  その値）を自動的に反映する**。そのため、ステップ5の結果は素朴に期待する
  `88/(n*c)`（`n` が未確定のまま残る形）ではなく、既に `n=6` が織り込まれた
  `44/(3c)` になる。**バグではなく P2 の意図した挙動**（「シンボルを定義したら
  以降の演算に自動的に反映される」）— ただし、代入の**順序**（先に $n$ の値を
  確定させてから $\eta$ の式へ進む）が結果に影響する点は把握しておく必要がある。
