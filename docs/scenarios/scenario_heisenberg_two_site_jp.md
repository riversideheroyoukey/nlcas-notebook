# 実践ループ サンプルシナリオ：ハイゼンベルクモデル（2サイトスピン鎖）

> （旧「E-3 研究ワークフロー検証シナリオ」を **1シナリオ＝1セッション**に分割した独立シナリオ。）

**バックエンド:** Julia（第二量子化）／**ドメイン:** スピン系（spin_systems）。

### 物理的背景

磁性体の最も基本的なモデル。2サイトのスピン-1/2 鎖で厳密対角化が可能。
世間での需要が高く（磁気共鳴・量子情報・凝縮系物理）、教育的にも重要。

$$H = J\, \mathbf{S}_1 \cdot \mathbf{S}_2 = J\left( S_1^z S_2^z + \frac{1}{2}\left( S_1^+ S_2^- + S_1^- S_2^+ \right) \right)$$

ここで $J > 0$：反強磁性結合、$J < 0$：強磁性結合。

エネルギー固有値（厳密解）：
- 一重項（singlet）$|S=0\rangle$：$E = -3J/4$
- 三重項（triplet）$|S=1\rangle$：$E = +J/4$（3重縮退）

検証すべき物理：
1. $[H, S_z^{\rm tot}] = 0$（全 z スピン保存）
2. $[H, S_z(1)]$ が非ゼロ（個々のサイトは保存しない）
3. Heisenberg EOM による運動方程式の確認

#### HB-2b: $S^+$/$S^-$ の手動定義

`Sp`/`Sm` は `@tlsxyz_ops` と `@tlspm_ops` の混在によるバグ回避のため自動定義しない。
$S^\pm$ が必要な場合は $S^x, S^y$ の一次結合として登録する。

**入力する式:**
```
Sp_1 = Sx_1 + i * Sy_1
Sm_1 = Sx_1 - i * Sy_1
Sp_2 = Sx_2 + i * Sy_2
Sm_2 = Sx_2 - i * Sy_2
```

| 項目 | 内容 |
|---|---|
| 入力 | 上記を順次登録（E1〜E4） |
| 確認 | 各式が $S_1^x + iS_1^y$ 等の形で表示されること |
| 結果 | |

#### HB-3: ハミルトニアン入力

**入力する canonical 表記（Sx/Sy/Sz で直接書く）:**
```
H = J * Sz_1 * Sz_2 + J/4 * (Sx_1 * Sx_2 + Sy_1 * Sy_2)
```
$J/4 (S_1^x S_2^x + S_1^y S_2^y) = J/2 (S_1^+ S_2^- + S_1^- S_2^+)$ をQA規約で表したもの。

> **注意：** 数式入力欄では式番号（E1, E4 等）を数式の中に埋め込むことはできない。
> 式番号は `[E1, E2]` や `E1 を微分して` のような操作指示でのみ使用可能。

| 項目 | 内容 |

| 確認 | $J S_1^z S_2^z + J/4(S_1^x S_2^x + S_1^y S_2^y)$ の形で表示 |
| 結果 | |

## generator コマンド（この `scenario` ブロックが生成の単一ソース）

```scenario domain=spin_systems
@note: 2サイトのスピン-1/2 ハイゼンベルクモデルを扱う。結合定数 $J$（$J>0$ は反強磁性結合、$J<0$ は強磁性結合）と、両サイトで使うスピン演算子 $S$ を準備する。
J を実数パラメータとして定義して
S をスピン演算子として定義して
@note: 昇降演算子 $S^\pm=S^x\pm iS^y$ を、サイト1・2それぞれについて既存の $S^x,S^y$ の一次結合として明示的に定義する。
Sp_1 = Sx_1 + i * Sy_1
Sm_1 = Sx_1 - i * Sy_1
Sp_2 = Sx_2 + i * Sy_2
Sm_2 = Sx_2 - i * Sy_2
@note: ハイゼンベルクハミルトニアン $H=J\mathbf S_1\cdot\mathbf S_2=JS_1^zS_2^z+\frac{J}{4}(S_1^xS_2^x+S_1^yS_2^y)$ を登録する（第2項は $S^x,S^y$ で表した $S_1^+S_2^-+S_1^-S_2^+$ に相当する）。
H = J * Sz_1 * Sz_2 + J/4 * (Sx_1 * Sx_2 + Sy_1 * Sy_2)
@note: 全 $z$ 方向スピン $S_z^{\rm tot}=S_1^z+S_2^z$ を登録する。
Sztot = Sz_1 + Sz_2
@note: ハミルトニアン $H$ と全スピン $S_z^{\rm tot}$ の交換子を、それぞれ先ほど付けた名前で参照して計算する（ブラケット記法は E番号と同じ仕組みで名前付きシンボルも解決する）。ゼロになれば、全 $z$ 方向スピンは保存量である（SU(2) 対称性に由来）。
[H, Sztot]
@note: 個々のサイトのスピンは必ずしも保存しない。サイト1の $S^z$ に対するハイゼンベルク方程式（運動方程式）を求め、非ゼロの結合項が現れることを確認する。
Sz_1 の Heisenberg 方程式 E5
@note: 同様に、サイト1の $S^x$ に対するハイゼンベルク方程式を求める。
Sx_1 の Heisenberg 方程式 E5
```
