# 実践ループ シナリオ：スピンありフェルミオンの1次摂動項

> 2026-08-09 実施。**スピンありの一般ハミルトニアン**（任意基底・スピン依存）を書き、
> 相互作用との交換子——摂動展開の1次で現れる形——まで通すことを確認する。
> 対になる[行列要素の定義シナリオ](scenario_spinful_matrix_elements_jp.md)の後半にあたる。

**バックエンド:** Julia（QuantumAlgebra.jl）／**ドメイン:** 凝縮系物理（condensed_matter）。

### なぜこれが確認に値するのか

前半のシナリオで定義した係数を使うと、ハミルトニアンは

$$\hat H_0=\sum_{m\sigma,n\sigma'} h_{m\sigma,n\sigma'}\,\hat c^\dagger_{m\sigma}\hat c_{n\sigma'},
\qquad
\hat V=\sum V_{m\sigma_1,n\sigma_2,p\sigma_3,q\sigma_4}\,
\hat c^\dagger_{m\sigma_1}\hat c^\dagger_{n\sigma_2}\hat c_{p\sigma_3}\hat c_{q\sigma_4}$$

と書ける。**任意基底・スピン依存**の一般形で、$k$ 空間に特殊化していない。摂動展開の
1次で必要になるのは $[\hat H_0,\hat V]$ で、これは縮約のたびに**新しい束縛添字**を生む。

ここが表示の勝負どころで、2026-08-08 まで2つ壊れていた:

- 添字が**区切り無しで連結**され、$\sum_{mnpq}$・$V_{mnpq}$ になっていた。このプロジェクト
  自身の規則ではこれは「$mnpq$ という名の1添字」であり、**表示を再入力すると別の式になる**
- 縮約で新しく出た束縛添字が **`k_{5}` のような中立名**で、$m,n,p,q$ の隣に並ぶと
  論文に載せられない

摂動の次数を上げれば因子が増え、添字はさらに増える。**その TeX がそのまま論文に使えるか**が
このシナリオの問いである。

### 物理の筋

1. 電子の消滅演算子 $\hat c$ を定義する
2. 1体項 $\hat H_0$ を書き、正規順序に置く（既に正規順序なので不変）
3. 相互作用 $\hat V$ を書き、正規順序に置く
4. $[\hat H_0,\hat V]$ を取る → 1次摂動項

4 の構造は手で追える: $[\hat c^\dagger_a\hat c_b,\ \hat c^\dagger_c\hat c^\dagger_d\hat c_e\hat c_f]$ は
$\hat c_b$ と $\hat c^\dagger_c,\hat c^\dagger_d$ の縮約、$\hat c^\dagger_a$ と $\hat c_e,\hat c_f$ の縮約から
**4項**出る。どの項も4つの演算子を残し、縮約で消えた添字の代わりに**新しい束縛添字が1組
（モードとスピン）**入る。

## 確認された挙動・注意点

**束縛添字は文字を消費しない。** 束縛添字は和の中だけの使い捨てラベルなのに、
縮約のたびに $r$→$s$→$t$ と消費すれば、研究者が新しい量に使える文字が減っていく。
実際 $r$ を半径として宣言してあっても束縛添字が $r$ を奪っていた（実測 2026-08-08）。
そこで**利用者自身が書いた文字を循回して添字を付ける**（$m_1,s_1,n_1,t_1,\dots$）。
モードの隣にモード、スピンの隣にスピンが来るので読み筋も合う。

**「どの文字が空いているか」は表示層には分からない。** その式に出ていないのは偶然で、
利用者は $i$・$j$・$k$ をどこでも普通に使う。添字を付けておけば、その判断自体が要らない。

**場の演算子の展開式そのものはここには書けない。** $\hat\psi_\sigma(\mathbf x)=\sum_m
\varphi_{m\sigma}(\mathbf x)\hat c_{m\sigma}$ は基底関数（Maxima 側の関数）と QA 演算子の積で、
Julia セッションでは $\varphi_{m,s}(x)$ が理由付きで断られる
（`parser.unsupported_notation.julia_applied_indexed`——QA 演算子は添字を取るが、
その結果は呼び出せない）。**バックエンドはセッション固定**（原則#6）なので、
基底側は[前半のシナリオ](scenario_spinful_matrix_elements_jp.md)の仕事になる。

**確認日:** 2026-08-09（実機 Julia、ST-1〜4 完走）。
