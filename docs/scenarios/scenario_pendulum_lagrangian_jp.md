# 実践ループ サンプルシナリオ 2：単振り子の解析力学

**物理的テーマ:** Lagrangian から Euler-Lagrange 方程式を導出し、小角近似で単振動に帰着させる  
**バックエンド:** Maxima（standard_symbolic セッション）  
**ドメイン:** 解析力学（analytical_mechanics）  
**所要時間:** 約 15 分  
**検証目的:** Maxima バックエンドの基本ワークフロー（微分・代入・整理・方程式形式）の使い勝手確認

## 物理的背景

単振り子の Lagrangian（$l$ = 振り子長、$q$ = 角度、$m$ = 質量）：

$$L = \frac{1}{2}m l^2 \dot{q}^2 - mgl(1-\cos q)$$

Euler-Lagrange 方程式：

$$\frac{d}{dt}\frac{\partial L}{\partial \dot{q}} - \frac{\partial L}{\partial q} = 0$$

$$\Rightarrow \quad ml^2\ddot{q} + mgl\sin q = 0$$

小角近似 $\sin q \approx q$：

$$\ddot{q} + \omega^2 q = 0, \qquad \omega = \sqrt{g/l}$$

---

## 前定義の方針（重要）

このシナリオでは**式を書く前にすべての記号を宣言する**。前定義により：

1. **`\dot{q}` 表示と d/dt 演算が正しく機能する**（`q` の時間依存宣言）
2. **未定義シンボル警告が出ない**（`m`, `l`, `g` のスカラー宣言）
3. **積の記述でスペースが使える**（括弧のない積。例 `m l^2` → $ml^2$）

> **括弧前の積はスペースでも `*` でも可:**  
> `m g l (1 - cos(q))` のように括弧の直前をスペースにしても、`m g l` が関数でない
> ため積として解釈されます（`m g l * (1 - cos(q))` と等価）。確実を期すなら `*` を
> 明示しても構いません。`sin`/宣言済み関数だけはスペースがあっても関数呼び出しです。

### ステップ 4：$\partial L/\partial q$（Euler-Lagrange 右辺）

```

```

**期待する出力:** E4 = $-mgl\sin q$

- [ ] `cos(q)` の q 微分 → `-sin(q)` が得られるか

> Maxima の連鎖律が `diff(q(t),t,1)` にも作用して余分な項が出ます。

> ユーザーは手動の置換手順を踏む必要はありません。

## 既知の注意点

| 注意点 | 詳細 |
|---|---|
| **前定義は必須** | ステップ 0 を省略してはならない。後から宣言しても既存の式には遡及しない。セッションをやり直す必要がある |
| **`q_dot` は使用不可** | `q_dot` は独立変数として扱われ、`\dot{q}` 表示にならず `d/dt(q_dot) = 0` となる |
| **括弧前はスペースでも可** | `m g l (1 - cos(q))` のように括弧前をスペースにしても積として解釈される（`m g l * (…)` と等価）。`*` を明示しても可。`sin`/宣言済み関数だけはスペースでも呼び出し |
| **`\dot{q}` の入力** | TeX 書法 `\dot{q}` と `diff(q,t)` はどちらも同じ canonical に変換される |
| **`g/l` パターン代入** | `g/l` という比の代入はパターンマッチが必要。通らない場合は再評価（`omega^2 = g/l` 登録後）を試す |
| **`\ddot{q}` への solve** | H-9 で微分記号を solve 変数に指定できる。内部で `block([_nb_dv], solve(subst(diff=_nb_dv,...)), subst(...))` パターンを使用 |
| **ロード済み式への代入** | セッションをロードした後でも `\ddot{q}` を LHS とする代入が使える。`lhs_latex_to_canonical()` が `\ddot{q}` → `'diff(q(t),t,2)` に変換する |
