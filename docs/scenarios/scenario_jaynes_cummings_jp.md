# 実践ループ サンプルシナリオ：Jaynes-Cummings モデル（光子と2準位分子の相互作用）

> （旧「E-3 研究ワークフロー検証シナリオ」を **1シナリオ＝1セッション**に分割した独立シナリオ。）

**バックエンド:** Julia（第二量子化）／**ドメイン:** 量子光学（quantum_optics）。

### 物理的背景

分子（または2準位原子）と単一光子モードの相互作用。量子光学・分子分光の基本モデル。

$$H_{\rm JC} = \omega\, a^\dagger a + \omega_0\, S_z + g\left( a\, S^+ + a^\dagger\, S^- \right)$$

ここで：
- $a$, $a^\dagger$：光子の消滅・生成演算子（ボゾン）
- $S_z$, $S^\pm = S_x \pm iS_y$：分子の2準位演算子（スピン 1/2）
- $\omega$：光子周波数、$\omega_0$：分子遷移周波数、$g$：光・物質結合定数

Heisenberg 方程式で得られる運動方程式：

$$\dot{a} = -i\omega\, a - ig\, S^-$$
$$\dot{S}^- = -i\omega_0\, S^- + 2ig\, S_z\, a$$

共鳴条件 $\omega = \omega_0$ のとき、Rabi 振動が現れる。
