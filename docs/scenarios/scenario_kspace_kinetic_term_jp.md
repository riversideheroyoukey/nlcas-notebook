# 実践ループ シナリオ：k 空間の運動項 $\xi_k c^\dagger_k c_k$（添字つきスカラー）

> 2026-08-03 実施。凝縮系でいちばん普通に書かれる形——**添字つきのスカラーが演算子に掛かる**式
> ——が Julia セッションで書けることを、正規順序と交換子まで通して確認する。

**バックエンド:** Julia（QuantumAlgebra.jl）／**ドメイン:** 凝縮系物理（condensed_matter）。

### なぜこれが確認に値するのか

$\xi_k c^\dagger_k c_k$ は教科書の最初のページに出てくる書き方だが、**2026-08-02 まで書けなかった**。
`xi_k` は QuantumAlgebra から見ると「添字を持つ c 数」で、Julia 側にその綴りが無かったためで、
CAS は `Sym xi is not callable` と答えていた（open_items JULIA-INDEXED-SCALAR）。

解決は `param(:xi, k)` に一本化すること。**実測して選んだ**——`param` は QA 演算子との積・
`normal_form`・param 同士の演算・Symbolics 変数との積まで通り、latex は `\xi_{k}`＝
**利用者自身の添字**なので表示ブリッジも要らない。対する `Symbolics.@syms` は表示が `xi(k)`
（CAS 構文の漏れ）で、そもそも QA 演算子と掛けられない。

**宣言が根拠。** 宣言のない `V_i` は従来どおり理由付きで断る——非束縛の添字を無条件に `param`
へ流すと、`\sum_k xi_k c'_k c_k` の構造トークン `sum` 自身が `param(:sum, k)` になり、
**拒否が黙って無意味な積に変わる**（実測、2026-08-02）。

### 物理の筋

1. 運動項 $\xi_k c^\dagger_k c_k$ を書き、正規順序に置く（既に正規順序なので不変）
2. わざと逆順の $\xi_k c_k c^\dagger_k$ を含むハミルトニアンを書き、正規順序に直す
   → 反交換関係 $c c^\dagger = 1 - c^\dagger c$ が効いて定数項が出る
3. $[H, c_k]$ を計算する → $\xi_k c_k - \Delta c^\dagger_{-k}$

3 は手で確かめられる: $[c^\dagger_k c_k, c_k] = -c_k$、
$[c^\dagger_k c^\dagger_{-k}, c_k] = -c^\dagger_{-k}$（$k\neq0$）。

## 確認された挙動・注意点

**唯一できないのは微分。** `param` に対する `Differential(::QuExpr)` は Julia 側にメソッドが無い。
これは MethodError のままにせず言葉に翻訳してある（`error.julia_quexpr_not_differentiable`——
添字なしで宣言し直すか、スカラー部を Maxima セッションへ渡す、と案内する）。後者が
[S-c シナリオ](scenario_bcs_gap_equation_jp.md)の道。

**宣言していない添字つきスカラーは断られる。** `V_i` のように宣言のない基底は
`parser.unsupported_notation.julia_indexed_scalar` で理由と対処（`V_i` を宣言する／
添字ダイアログの「名前の一部」）を示して断る。**これは欠陥ではなく設計**——上に書いた
とおり、無条件に通すと拒否が silent-wrong に変わる。

**確認日:** 2026-08-03（実機 Julia、ST-1〜4 完走）。
